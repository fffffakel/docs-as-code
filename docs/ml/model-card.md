# Model Card

## Общая информация
**Название модели:**  
Qwen2.5-7B-Instruct

**Источник:**  
Hugging Face Hub (`Qwen/Qwen2.5-7B-Instruct`)

**Автор / организация:**  
Qwen Team, Alibaba Cloud

**Задача модели:**  
Text Generation, генерация ответов по контексту

**Язык:**  
Многоязычная модель (включая русский и английский)

## Использование в проекте
Модель используется в RAG-сервисе для создания ответов по найденным регламентам компании.
Сгенерированный моделью ответ возвращается пользователю через эндпоинт `POST /questions` вместе со ссылками на первоисточники.

## Входные данные
Текстовый промпт, содержащий системную инструкцию («отвечай только по предоставленным документам»), извлечённые фрагменты корпоративных документов (контекст) и вопрос сотрудника.

## Выходные данные
Текст ответа на естественном языке с цитированием или указанием названия документа-источника.

## Метрики качества
По данным авторов модели на бенчмарках:
- HumanEval: 84.8%
- GSM8k: 91.6%
- Поддержка контекста до 128k токенов.

## Ограничения
1. Модель может генерировать фактические ошибки (галлюцинации), если контекст запроса является неоднозначным.
2. Качество ответов может снижаться при сложном форматировании таблиц или плохо распознанном OCR-тексте.
3. Модель может привносить общие знания из предобучения вместо строгих корпоративных регламентов при отсутствии релевантного контекста.

## Не рекомендуется использовать
- Для принятия юридически обязывающих решений и финансовых расчётов без ручной проверки человеком.
- Для обработки и генерации конфиденциальных персональных данных в открытом внешнем контуре.
