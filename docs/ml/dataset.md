# Data Sheet

## Общая информация
**Название датасета:**  
SberQuAD (Sber Russian Question Answering Dataset)

**Источник:**  
Hugging Face Datasets

**Назначение:**  
Оценка и тестирование способности языковой модели находить точный ответ на вопрос по предоставленному фрагменту текста на русском языке.

## Состав данных
**Объём:**  
Около 50 000 вопросов и фрагментов текста.

**Тип данных:**  
Размеченный текстовый корпус (вопрос, контекст параграфа, точный фрагмент ответа).

**Основные поля / признаки:**  
- `id` — уникальный идентификатор записи;
- `title` — название статьи;
- `context` — текст фрагмента статьи;
- `question` — вопрос к тексту;
- `answers` — точный ответ и его начальная позиция в тексте.

## Получение данных
Корпус собран на основе русскоязычного сегмента Википедии. Вопросы и ответы сформулированы разметчиками вручную.

## Предобработка
Тексты нормализованы, удалены спецсимволы разметки, данные валидированы кросс-проверкой разметчиков.

## Ограничения
- Тексты взяты из энциклопедических статей, поэтому стиль изложения отличается от корпоративных регламентов и служебных записок.
- В вопросах преобладают фактологические ответы, отсутствуют сложные многосоставные корпоративные выражения.

## Использование в проекте
Датасет используется для предварительной валидации и тестирования качества генерации ответов (проверка того, насколько точно модель опирается на переданный контекст и не галлюцинирует).
