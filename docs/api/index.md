# API

API предоставляет доступ к функциям корпоративного RAG-агента.

## Основные операции

- `POST /questions` — отправить вопрос и сгенерировать ответ с источниками;
- `GET /questions/{id}` — получить ранее сформированный ответ по ID;
- `GET /documents` — получить список документов в базе знаний.

## Спецификация

Полная спецификация доступна в файле [openapi.yaml](openapi.yaml).
