# ИИ-ассистент по внутренней документации компании

Сервис автоматически ищет информацию во внутренней документации компании и генерирует точные ответы на вопросы сотрудников со ссылками на первоисточники.

Основные пользователи:
- сотрудник;
- администратор базы знаний.

Основные функции:
- отправка вопроса по регламентам;
- поиск релевантных документов и генерация ответа;
- индексация новых документов базы знаний.

## Комплект документации

1. Описание проекта — предназначено для всей команды, содержит цели и базовые функции системы.
2. Требования — предназначены для разработчиков и тестировщиков, описывают пользовательские сценарии и критерии приёмки.
3. Архитектура системы — предназначена для разработчиков, фиксирует устройство RAG-пайплайна и используемые базы данных.
4. Документация API — предназначена для интеграторов, описывает интерфейсы взаимодействия с сервисом.
5. Документация ML-модели — предназначена для ML-инженеров, фиксирует используемые эмбеддинги и языковую модель.
